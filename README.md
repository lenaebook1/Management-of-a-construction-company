# Объект 360 - Информационная система управления строительным объектом

Веб-приложение для управления задачами строительной бригады, закупками материалов и бюджетом объекта. 

В рамках проекта использовались такие инструменты, как:
- Массивы и объекты JavaScript
- События и DOM-манипуляции
- Локальное хранилище (`localStorage`)
- Формирование и экспорт отчетов (CSV)

##  Функционал приложения
- **Панель статистики**: отображение общего количества задач, выполненных работ, расходов и остатка бюджета.
- **Управление задачами**: добавление, удаление, отметка выполнения, фильтрация (все/в работе/выполненные/срочные), установка приоритетов.
- **Закупки материалов**: таблица закупок с автоматическим расчетом стоимости позиций и общей суммы.
- **Финансовый контроль**: установка лимита бюджета, визуальный индикатор расходов, предупреждение о превышении бюджета.
- **Сохранение данных**: автоматическое сохранение состояния приложения в браузере через `localStorage`.
- **Экспорт отчета**: генерация и скачивание CSV-файла со сводкой по задачам и материалам.
- **Адаптивность**: корректное отображение на десктопах, планшетах и мобильных устройствах.

##  Технологии
- **HTML5** - семантическая разметка
- **CSS3** - стилизация, Grid/Flexbox, адаптивный дизайн, CSS-переменные
- **JavaScript (ES6+)** - логика приложения, работа с DOM, события, LocalStorage, экспорт данных
